# アプリのバッジを Pinstage に出す

Pinstage は、Dock のアイコンに出る標準のバッジ（赤い点・数）を、ウインドウバーとウインドウスイッチャーのアイコンにも写します。
それとは別に、アプリが決まった場所に小さな JSON を書くと、その件数を Pinstage のアイコンにバッジとして出せます。
Pinstage は特定のアプリを名指ししていません。この形式で書けば、どのアプリでも出せます。

## 置く場所

```
~/Library/Application Support/Pinstage/BadgeSources/<バンドル ID>.json
```

- ファイル名は、書くアプリ自身のバンドル ID に `.json` を付けたもの（例：`com.example.MyApp.json`）
- フォルダがなければ、アプリ側で作る
- バンドル ID に使える文字は、英数字・`.`・`-`・`_`。`.` で始まる名前（隠しファイル）は読まない

## 中身

```json
{
  "version": 1,
  "bundleID": "com.example.MyApp",
  "pid": 12345,
  "updatedAt": 1764000000.5,
  "badges": [
    { "corner": "topRight", "count": 3, "label": "未読", "color": "#45C66D" },
    { "corner": "topLeft", "count": 1, "label": "作業中" }
  ]
}
```

| 項目 | 書くこと |
|---|---|
| `version` | いまは `1` だけ |
| `bundleID` | 書くアプリのバンドル ID。ファイル名と同じにする |
| `pid` | 書くアプリのプロセス ID |
| `updatedAt` | 書いた時刻（UNIX 時刻・秒。小数も可） |
| `badges` | 出すバッジ。3 つまで |
| `badges[].corner` | アイコンのどの角に出すか。`topLeft`・`topRight`・`bottomLeft` のどれか（右下は Pinstage が使う） |
| `badges[].count` | 件数。0〜1,000,000。100 以上は `99+` と出る。0 は出さない |
| `badges[].label` | 何の件数か（例：未読）。32 文字まで。読み上げと説明に「未読 3 件」の形で使う |
| `badges[].color` | バッジの色（`#RRGGBB`）。省くと標準の色 |

## Pinstage が読むときの決まり

- **起動中のアプリのものだけ使う**：そのバンドル ID のアプリが起動していて、`pid` がそのプロセスと同じで、`updatedAt` がそのアプリを起動した時刻より後のときだけ使う。アプリが終了したら、ファイルが残っていても出さない
- **未来の時刻は断る**：`updatedAt` が Pinstage の時刻より 5 秒以上先なら読まない
- **形が合わないファイルは丸ごと読まない**：項目が足りない・角が重なる・件数や色の形が違う、などのとき。そのアプリは Dock の標準のバッジに戻る
- **標準のバッジより優先する**：有効なファイルがあるアプリは、Dock のバッジの代わりにファイルの内容を出す。`badges` が空（または全部 0 件）なら、Dock にバッジがあっても何も出さない
- **大きさ**：8 KB まで。普通のファイルだけを読み、シンボリックリンクはたどらない
- **読む間隔**：2 秒に 1 回まで。置き場のファイルは 32 個まで読む（名前順）

## 書く側のすすめ

- 件数が変わったときに書き直す。書きかけを読まれないよう、同じフォルダに別の名前（例：`com.example.MyApp.json.tmp`）で書いてから名前を変える
- アプリを起動したら、件数が 0 でも一度書く（Pinstage を後から起動しても、いまの数が出るように）
- 終了するときにファイルを消さなくてもよい（Pinstage は起動中のアプリのものしか使わない）
