# 手で確かめること

画面の操作は自動のテストで確かめにくいので、変えたところに関係する項目を、`make run` で起動して手で確かめます。

## 起動と許可

- [ ] 設定 →「一般」の「ログイン時に起動」をオンにすると、システム設定の「ログイン項目」に Pinstage が入る（許可が要るときは案内が出る）。ログインし直すと起動する
- [ ] macOS のステージマネージャをオンにすると、数秒でウインドウバーに案内が出る（× で、この起動の間は閉じられる）。設定の「一般」にも「オフにする」が出る。オフにすると案内が消える

- [ ] 初めて起動すると、アクセシビリティの許可を求められる。許可するまで、ウインドウバーに案内が出る
- [ ] 許可すると、数秒でウインドウバーにウインドウが並ぶ（起動し直さなくてよい）
- [ ] メニューバーにアイコンが出て、Dock には出ない

## ステージ

- [ ] ウインドウバーの行をクリックすると、そのウインドウが最前面に出る（大きさは変わらず、ウインドウバーと重なるところだけ右へずれる）
- [ ] 設定の「1 枚だけ出すときの大きさ」を「縦いっぱい」にすると、1 つだけクリックしたウインドウが、幅はそのまま縦いっぱいになる。「そのまま」「ステージいっぱい」もそのとおりになる
- [ ] Safari を 2 枚、Finder を 2 枚開いて、Safari と Finder を 1 枚ずつ ⌘＋クリックで並べたとき、選んでいないもう 1 枚が前に出てこない
- [ ] しまってあった（最小化した）ウインドウをクリックすると、戻ったあと正しい位置・大きさに並ぶ
- [ ] 別の操作スペースに移って戻っても、ウインドウバーの並び順が崩れない。前に出したウインドウが変わったときは、青い枠がそれに合う
- [ ] 行をダブルクリックすると、そのウインドウだけがステージいっぱい（常に出すときはウインドウバーの右側いっぱい）に広がって前に出る
- [ ] ⌘＋クリックで 2 つ目を足すと、2 つが左右に並んで最前面に出る
- [ ] もう一度 ⌘＋クリックすると、ステージから外れ、残りが並び直す
- [ ] 行をウインドウバーの外（右）へドラッグして離すと、ステージに足される
- [ ] 行をウインドウバーの中で上下にドラッグすると、落とす位置に青い線が出る。離すとその位置へ移る（自分のすぐ上・すぐ下では線が出ない）
- [ ] 並べ替えたあとにウインドウを開け閉めしても、並び順が保たれる（新しいウインドウは末尾＝下、上下に置いたときは右に入る）
- [ ] 並べ替えてから Pinstage を終了し、起動し直すと、同じ並び順に戻る（止めている間に開いたウインドウは末尾に入る）
- [ ] しまってある（最小化した）ウインドウも、出すと元に戻って並ぶ
- [ ] 前に出しているウインドウの行は、色の付いた枠で分かる
- [ ] 2 枚を並べてから、Dock・Mission Control（4 本指で上にスワイプ）・⌘＋Tab で組み合わせ外のウインドウを前に出すと、青い枠はそのウインドウだけに付き、位置と大きさは変わらない。続けて ⌘＋クリックすると、そのウインドウに足される
- [ ] Mission Control やアプリの「ウインドウ」メニューで同じアプリの別のウインドウを選んだときも、実際に選んだウインドウに青い枠が付く。すでに組み合わせに入っているウインドウを前に出しただけなら、組み合わせは変わらない
- [ ] Mission Control を開いて選ばずに閉じたときや、Pinstage がグループを呼び出して順に前に出しているときは、青い枠が別のウインドウに切り替わらない
- [ ] 違うアプリのウインドウを組み合わせても、すべて最前面に出る
- [ ] 行の右クリック →「ウインドウを閉じる」で閉じる。保存していない書類なら、アプリが保存するかを聞く。閉じたら行が消える
- [ ] 行の右クリック →「〇〇を終了」でアプリが終了し、そのアプリの行がすべて消える
- [ ] 前に出している行の右クリック →「ステージから外す」で外れ、残りが並び直す

## 並べ方

- [ ] 並べ方のメニューに「自動（枚数に合わせる）」「左右に並べる」「上下に並べる」「4 分割」「6 分割」「左を大きく」が並ぶ（「重ねる」はない）。変えると、その場で並び直す
- [ ] 4 分割に 3 枚出すと、右下の枠が空く。6 枚出すと、5・6 枚目は右下の枠に重なる。6 分割も同じ
- [ ] 並べ方を変えたとき、Chrome・Slack などのウインドウも、少し遅れて決めた枠にぴったり収まる（はみ出したままにならない）。アプリがそれより小さくできない枠では、はみ出すことがある（そのときは ~/Library/Logs/Pinstage/desktops.log に「並べたときのずれ」が残る）
- [ ] 前に「重ねる」で保存したグループは、「自動」で並ぶ
- [ ] 並べ方のメニュー・グループの編集画面に「余白を空ける」はない（並べたウインドウは、いつもすき間なく並ぶ）
- [ ] ウインドウを手で動かし（重ねたり、間を空けたり）、「いまの並びを型として登録」すると、並べ方のメニューに「マイ型 1」が出る
- [ ] 別のウインドウを選んで「マイ型 1」にすると、同じ形で並ぶ
- [ ] 登録した型の名前を変える・削除できる。削除した型を使っていたグループは「自動（枚数に合わせる）」になる

## グループ

- [ ] 「グループ」の見出しの ＋ →「ステージをグループとして保存」で、グループに「グループ 1」が並ぶ
- [ ] 別のウインドウを出したあとグループを押すと、保存した組み合わせと並べ方で出る
- [ ] ⌃⌥1 で 1 番目のグループが出る
- [ ] グループの右クリックで、名前を変える・並べ替える・削除できる
- [ ] グループの右クリック →「編集…」で編集画面が開く。名前・中身（ウインドウを足す・− で外す・ドラッグで並べ替え）・並べ方・ディスプレイを変えて保存すると、ウインドウバーの見本と、呼び出したときの並びが変わる
- [ ] 別の組み合わせを前に出して、グループの右クリック →「いまのステージで上書き保存」で中身が入れ替わる（名前と並び順はそのまま）

### 見えている画面を記録

- [ ] ウインドウを手で動かして重ねたり大きさを変えたりしたあと、「グループ」の見出しの ＋ →「見えている画面を記録」を押すと、見えているウインドウがすべて入ったグループが増える。見本が、いまの画面と同じ形・重なりになる
- [ ] 最小化したウインドウ・隠したアプリ（⌘H）のウインドウ・ほかのデスクトップのウインドウ・ほかのディスプレイのウインドウは入らない
- [ ] ウインドウを動かしたあと、そのグループを押すと、記録したときの位置・大きさ・重なりの順番に戻る。並べ方のメニューで「記録した配置」に印が付く
- [ ] 並べ方のメニューでほかの型を選ぶと、そちらで並び直る（記録した配置の印は消える）
- [ ] メンバーのアプリを 1 つ終了してから呼び出すと、起動し直して記録した枠に置く。起動できなかったときも、ほかのウインドウの枠はずれない
- [ ] グループの右クリック →「見えている画面で上書き記録」で、いまの見た目に入れ替わる（名前と並び順はそのまま）
- [ ] 細い帯（アイコンの並びを 1 列まで狭めたとき）でも、グループの上の ＋ から記録できる
- [ ] 設定の「ショートカット」で「見えている画面をグループとして記録」を割り当てると、ポインタのあるディスプレイの画面を記録する（初期設定は割り当てなし）
- [ ] 編集画面で、記録したグループの並べ方が「記録した配置」と出る。ほかの型に変えて保存すると、そちらになる
- [ ] ウインドウの行をグループの行の上へドラッグすると、グループの行が光り、離すとそのグループに足される（見本にアイコンが増える）。もう入っているウインドウなら何も変わらない
- [ ] ウインドウの行をグループの上へドラッグしている間は、並べ替えの線が出ない。グループの外で離すと、これまでどおり並べ替え・ステージに足すになる
- [ ] グループの見本のアイコンを、グループの行の外へドラッグすると「−」の印が出て、離すとそのグループから外れる
- [ ] 見本のアイコンをほかのグループの行の上へドラッグすると、その行が光り、離すとそちらへ移る
- [ ] 並びの見本（中・大）で、アイコンを同じグループのほかのアイコンの上へドラッグすると、そのアイコンが光り、離すと 2 つの場所が入れ替わる。呼び出したときの並びも入れ替わる
- [ ] 細い帯の 2×2 でも入れ替わる。「アイコンの並び」の横 1 列では、離したアイコンの位置へ差し込まれる
- [ ] 同じグループの中の、アイコンのないところで離したときは、何も変わらない
- [ ] 最後の 1 つを外そうとすると、グループごと削除するか聞かれる。移して空になったときも、削除するか聞かれる
- [ ] 見本のアイコンをクリックしただけ（動かさない）なら、グループを呼び出す。グループの行のドラッグでの並べ替えも、これまでどおりできる
- [ ] 見た目が「アイコンの並び」（横 1 列）・細い帯（2×2）でも、アイコンをドラッグして外す・移すができる
- [ ] グループの欄をスクロールして隠れた行の位置で離しても、そのグループには入らない
- [ ] グループを 10 個くらい作っても、グループの欄だけがスクロールし、ウインドウの一覧が潰れない
- [ ] グループの行を上下にドラッグして並べ替えられる。ショートカットの番号も並びに合わせて変わり、起動し直しても残る。動かさずに離すとグループを呼び出す
- [ ] グループの行に、呼び出したときの並びの見本が出る（枠ごとに入るアプリのアイコン。並べ方・登録した型に合わせた形）
- [ ] 起動していないアプリのアイコンは薄く出る。ポインタを乗せると、中身の一覧（番号・アプリ・ウインドウの名前）が出る
- [ ] 大きさが「小」のときは、見本の代わりにアプリのアイコンが並ぶ
- [ ] グループの右クリックに「グループのアプリを終了…」は出ない
- [ ] グループの右クリック →「並べ方」に、用意した型・登録した型が並び、いまの型に印が付く（記録したグループは「記録した配置」にも印）。ほかの型を選ぶと、そのグループの並べ方が変わる（見本も変わる）
- [ ] グループの右クリックの「並べ方」で型を選ぶと、すぐステージに映る。そのグループを出したままならその場で並び直し、ほかのウインドウを出していたら、そのグループを選んだ並べ方で呼び出す
- [ ] Pinstage を終了して起動し直しても、グループと型が残っている
- [ ] グループの中のアプリを終了してからグループを押すと、アプリが起動し、ウインドウが出てから並ぶ
- [ ] ディスプレイを 2 つつないだとき、保存したときのディスプレイに並ぶ（ウインドウバーのないディスプレイでは画面いっぱいを使う）

## ウインドウバー

- [ ] いちばん上の帯に「🔍 検索 ⌃⌥Space」・並べ方・見た目・ピンが並ぶ。幅を狭めると、検索は「検索」だけ→虫めがねだけに縮み、見出しの文字が縦に折り返さない
- [ ] アイコンのボタンは同じ大きさで、ポインタを乗せると背景が出る。ピンは押すたびに「常に出す」「自動で隠す」が入れ替わる（常に出すときは青）
- [ ] 「ウインドウ」「グループ」の見出しに数が出る。いちばん下に、並べ方・保存の欄はない（そのぶん、ウインドウの一覧が広い）
- [ ] ウインドウ・グループの行は、ポインタを乗せると少し明るくなる。前に出しているウインドウは青い枠
- [ ] 上の帯の並べ方のボタンを押すと、用意した型・登録した型・型を作る項目が出る。ポインタを乗せると、いまの並べ方の名前が出る
- [ ] 「グループ」の見出しの右の ＋ を押すと、「ステージをグループとして保存」「見えている画面を記録」が出る。ステージが空なら「ステージをグループとして保存」は押せない
- [ ] ステージに出しているウインドウの行を右クリックすると、「ステージをグループとして保存」が出る（⌘＋クリックで複数選んだあと、そのまま保存できる）
- [ ] 細い帯（アイコンの並びを狭めたとき）では、上に検索・並べ方・見た目・ピンのアイコンが縦に並び、グループの上に ＋ が出る
- [ ] 同じアプリのウインドウを 2 つ以上開くと、ウインドウバーでとなりに並び、うすい枠（トレイ）で囲まれて、ひとまとまりに見える（上下に置いたときは横に囲む）。左右のアイコンの並びでも囲む（複数の列なら横に囲み、行の右端で折り返すときは、右端と次の行の左端で枠が開いたままになり、続いていることが分かる。1 列なら縦に囲む）
- [ ] 同じアプリの 2 つ目を開くと、そのアプリの最後のウインドウのすぐ後ろに入る（初めてのアプリは末尾）
- [ ] ウインドウを開くと、ウインドウバーのその位置に行が広がって現れ、ほかの行がすべるように動く。閉じると、行が縮んで消え、残りが詰まる（Chrome のタブと同じ）。ドラッグで並べ替えたときも、すべるように入れ替わる
- [ ] macOS の「アクセシビリティ」→「表示」→「視差効果を減らす」をオンにすると、動きが付かない
- [ ] アプリのウインドウの × ボタン・⌘W で閉じる、⌘M でしまう、⌘H でアプリを隠す、⌘Q で終了すると、ウインドウバーにすぐ（ほぼ待たずに）映る。新しく開いたウインドウも、すぐ並ぶ
- [ ] × で閉じてもウインドウを捨てずに隠すだけのアプリ（LINE など）でも、× を押すとすぐウインドウバーから消える。Dock のアイコンなどで出し直すと、前と同じ位置に戻る
- [ ] デスクトップを切り替えた直後に、行き先のウインドウが一瞬消えたりしない
- [ ] 設定の「同じアプリのウインドウをまとめる」がオン（初期設定）のときは、前から離れて並んでいた同じアプリのウインドウも、最初に出てくる位置にまとまる。ほかのアプリの間へドラッグすると、同じアプリのウインドウがまとまったまま動く
- [ ] まとめる設定のとき、同じアプリのまとまりの行をドラッグすると、最初から同じアプリの行がトレイごと一緒に動き、ほかのアプリの間で離すと、まとまりのまま移る。自分のまとまりの中・まわりには線が出ず、離しても動かない
- [ ] まとまりの行を、ウインドウバーの外（ステージ）やグループの上で離すと、まとまりのウインドウがすべて足される
- [ ] オフにすると、ドラッグで 1 つずつ離して置ける（離したものは、その位置のまま。ドラッグ中も、その行だけが動く）

- [ ] メニューバー →「自動で隠す」（または設定の「出し方」）にすると、ウインドウバーが、置いている辺の外へ隠れる。画面のその端にポインタを寄せると出て、離れると隠れる
- [ ] 「自動で隠す」のときは、ステージが画面いっぱいになる
- [ ] 枠を自前で描くアプリ（Kickoff など Electron のアプリ）のウインドウも、ウインドウバーに並ぶ。パネル・ツールチップ・メニューは並ばない

## ウインドウバーの後ろに入り込ませない（「常に出す」のとき）

- [ ] ウインドウのタイトルバーをダブルクリックすると、ウインドウバーの右側いっぱいに広がる（ウインドウバーの後ろに入り込まない）。もう一度ダブルクリックすると、元の大きさ・位置に戻る
- [ ] 緑のボタン（option を押しながら＝拡大）・ウインドウ メニューの「フィル」でも、ウインドウバーの右側に収まる
- [ ] ウインドウをドラッグしてウインドウバーの後ろへ入れると、ドラッグしている間はそのまま、離すとウインドウバーの右側へずれる
- [ ] Safari・Finder・ターミナル・Xcode など、いくつかのアプリで同じように効く（知らせを出さないアプリでも、1〜2 秒で戻る）
- [ ] その大きさより小さくできないアプリでも、何度も動かそうとしてちらつかない
- [ ] 設定の「ウインドウバーの後ろにウインドウを入り込ませない」をオフにすると、入り込んでも戻さない。「自動で隠す」のときは、この設定は選べず、戻さない
- [ ] ⌃⌥S でウインドウバーを隠している間は戻さない。出し直すと、入り込んでいたウインドウが右へずれる
- [ ] ウインドウバーの右の縁をドラッグして広げると、離したすぐあとに、新しい幅の後ろに入ったウインドウが右へずれる。前に出しているウインドウも、新しい幅で並び直る。ダブルクリックで広げたときも、新しい幅の右側いっぱいになる
- [ ] 狭めたときは、ウインドウバーの横にくっつけていたウインドウが、新しい幅の右端まで広がる（右端はそのまま）。離れたところにあるウインドウは動かない
- [ ] 狭めたあと、ウインドウのタイトルバーをダブルクリックすると、新しい幅の右側いっぱいに広がる（前の幅のぶんの余白が残らない）
- [ ] 幅を変えたあと Pinstage を開き直しても、同じ幅で出る
- [ ] ウインドウバーの上の帯のピンを押すと、「常に出す」と「自動で隠す」が入れ替わる（細い帯のときも、上の帯のピン）
- [ ] ピンで「自動で隠す」に変えても、ポインタがウインドウバーの上にある間は隠れず、離れると隠れる
- [ ] ⌃⌥S で、ウインドウバーを出す・隠すを切り替えられる
- [ ] 「自動で隠す」で ⌃⌥S を押すと、ウインドウバーが出たままになる（すぐ閉じない）。ポインタを一度ウインドウバーに入れて離すと隠れる。もう一度 ⌃⌥S でも隠れる
- [ ] ディスプレイを左右に並べ「自動で隠す」にしたとき、左のディスプレイの上で右のディスプレイのウインドウバーがちらつかない
- [ ] 行を別のディスプレイへドラッグして離すと、そのディスプレイのステージに足される
- [ ] ウインドウバーの見出しの見た目のボタン（または設定の「形式」）で、アイコンの並び・一覧・サムネイルの 3 つを選べる
- [ ] 「たたむ」のボタン・メニュー・設定・ショートカットは、もうない（細い帯にしたいときは、アイコンの並びを狭める）
- [ ] 見た目のメニューの「大きさ」（または設定の「大きさ」）で、小・中・大を切り替えられる。どの形式にもかかる（初期設定は小。前にアイコンの並びの大きさを選んでいたら、その大きさになっている）
- [ ] 「一覧」で大きくすると、行の高さ・アイコン・名前の文字が大きくなる。「小」は、いままでどおりブラウザの縦のタブと同じくらい
- [ ] 「サムネイル」で大きくすると、ウインドウが多くても、サムネイルが大きいまま並ぶ（収まらなければスクロール）。左下のアプリのアイコンと名前の文字も大きくなる
- [ ] 「アイコンの並び」で大きくすると、アイコンが大きくなり、1 行に入る数が減る。1 列のときの幅も広がる（小 52pt・中 58pt・大 64pt）
- [ ] 前に「細い帯」にしていたら、「アイコンの並び」になっている
- [ ] 前に「一覧・1 行」「一覧・2 行」にしていたら「一覧」、「サムネイル・中」「サムネイル・大」にしていたら「サムネイル」になっている
- [ ] 「一覧」は、ブラウザの縦のタブと同じくらいの大きさの 1 行（アイコンと名前）で並ぶ。ウインドウの数を変えても、行の高さは変わらない。多いときはスクロールする
- [ ] 一覧の行にポインタを乗せると、ウインドウの名前のすべてと、アプリの名前が出る
- [ ] 「サムネイル」で、ウインドウが少ないほど・ウインドウバーが広いほど、サムネイルが大きくなる
- [ ] 「アイコンの並び」で、内側の縁をドラッグして狭めていくと、列が減り、最後は 1 列の細い帯になる（それより狭くはならない。小 52pt・中 58pt・大 64pt）。途中で、上の帯と並べ方のボタンが、アイコンだけの縦並びに切り替わる（ドラッグしている間にも切り替わる）。「常に出す」なら、離したあとにステージが広がって、ウインドウが並び直す
- [ ] 細い帯でも、クリック・ダブルクリック・⌘＋クリック・ドラッグ・右クリックがほかの形式と同じに動く。ポインタを乗せるとウインドウの名前が出る
- [ ] 細い帯のグループは中身のアイコンが 2×2 で並び、下にショートカットが出る。並べ方・グループとして保存はアイコンのボタンで使える
- [ ] アイコンの並びを狭めたあと「一覧」「サムネイル」に切り替えると、一覧の幅（前に変えた幅）で出る。「アイコンの並び」に戻すと、狭めた幅に戻る。起動し直しても、どちらの幅も残る
- [ ] 一覧・サムネイルは、いままでどおり 160pt より狭くはならない
- [ ] 「アイコンの並び」にすると、ウインドウがアイコンだけの並びになる。ウインドウバーの幅に入るだけ 1 行に並び、名前はポインタを乗せると出る。もう一度押すと一覧に戻る
- [ ] アイコンの並びでも、クリック・ダブルクリック・⌘＋クリック・右クリック・ステージへのドラッグが動く。縦横にドラッグして並べ替えると、入る位置に縦の線が出る
- [ ] いちばん上（上下に置いたときは、いちばん左）へドラッグしたときも、入る位置に線が出る（ウインドウ・グループとも）
- [ ] アイコンの並びを狭めて 1 列にしたときは、ドラッグすると、アイコンとアイコンの間に横の線が出る（縦の線は出ない）。上下の位置で入る位置が決まる
- [ ] 落とす位置の線は、前後の行（アイコン）のちょうど真ん中に出る
- [ ] 行（アイコン）の上半分をつかんでも、下半分をつかんでも、ドラッグすると線が出る。ゆっくり・速く動かしても、線がちらつかない（一覧・サムネイル・アイコンの並び（1 列・複数の列）・上下の帯・グループとも）
- [ ] 同じアプリのまとまりは、まとまりのどの行をつかんでドラッグしても、線が出る
- [ ] ドラッグしている行（と、一緒に動くまとまりの行）は、ほかの行より手前に描かれる（下の行の下にもぐらない）
- [ ] いちばん上・いちばん下（アイコンの並びでは、行の左端・右端も）へドラッグしたときの線は、行に重ならず、一覧の端の隙間に出る（端の行がステージに出ていて青い枠でも、線と見分けられる）
- [ ] 細い帯（アイコン 1 列）で上下にドラッグしているとき、ポインタが帯から少し（24pt まで）横にはみ出しても線は消えず、並べ替えになる。それより外で離すと、ステージに出る
- [ ] いちばん下（上下に置いたときは、いちばん右）へドラッグしたときも、線が出る。ウインドウが多く、いちばん下までスクロールしているとき・アイコンの並びで最後のアイコンが行の右端にあるときも（ステージに出ている行・出ていない行とも）
- [ ] 「同じアプリのウインドウをまとめる」がオンのとき、ほかのアプリのまとまり（トレイ）の中へドラッグしても線は出ず、離しても並びは変わらない
- [ ] アイコンの並びのときは、サムネイルを撮らない（一覧に戻すと、また映る）
- [ ] 「サムネイル」でウインドウが少ないときも、行は大きさ（小・中・大）で決まった高さのままで、ウインドウバーの縦いっぱいには広がらない（下は空く）。多いときはスクロールできる
- [ ] 「サムネイル」でウインドウが多いときは、スクロールして見えている行の分だけ撮る。スクロールして見えてきた行は、すぐ撮られる
- [ ] ウインドウは数で区切られず、すべて並ぶ（「ほかのウインドウ（n）」のボタン・設定の「並べる数」はない）。多いときはスクロールでき、新しく開いたウインドウは末尾に入る
- [ ] ウインドウバーを押しても、前面のアプリのフォーカスが外れない
- [ ] 左のウインドウバーの右の縁（右のウインドウバーなら左の縁）にポインタを乗せると、左右の矢印のポインタになり縁が光る。ドラッグすると幅が変わる（狭すぎ・広すぎにはならない）
- [ ] 「常に出す」で幅を変え終えると、ステージのウインドウが新しい幅に合わせて並び直す。ほかのディスプレイのウインドウバーも同じ幅になる
- [ ] 「自動で隠す」で幅を変えても、ドラッグを終えた瞬間に隠れない
- [ ] 終了して起動し直しても、幅が残る

## 設定画面

- [ ] 設定のタブが、一般・ウインドウバー・型・ショートカット・自動化の順に並ぶ。どのタブも、縦にスクロールしなくても収まる高さ
- [ ] 「一般」のタブに、起動・ウインドウを出すとき・macOS の設定・バージョンが並ぶ。「ウインドウバー」のタブに、置き方・見た目・並べるウインドウが並ぶ
- [ ] ウインドウバーの並べ方のメニューの「型を管理…」で、設定の「型」のタブが開く
- [ ] 出し方・位置・大きさは、横に並んだボタンで選べ、右端がほかの行のスイッチ・メニューとそろっている
- [ ] 「ウインドウバーの後ろにウインドウを入り込ませない」は「出し方」のすぐ下にあり、「自動で隠す」のときは押せない
- [ ] 「macOS の設定」に、アクセシビリティ・画面収録・ステージマネージャの状態が並び、項目名の下に何に使うかが小さく出る。許可がない・オンのときは、システム設定を開くボタンになる
- [ ] Dock との重なり・画面収録の許可の案内は、説明の下の右にボタンが出る（説明が細く折り返さない）

## ウインドウバーの位置（上下左右）

- [ ] ウインドウバーは画面の端にすき間なく付く。ステージのウインドウとの間は、設定の「ステージとの間」の分（初期設定 8pt）空く（左右・上下とも）。設定で 0〜24pt に変えると、ステージに出しているウインドウがすぐ並び直す

設定の「位置」か、ウインドウバーの見出しの見た目のボタン →「位置」で切り替える。

- [ ] 「右」にすると、ウインドウバーが右端に縦長で出て、ステージはその左側になる。幅を変えるつまみは左の縁に出て、左へドラッグすると広がる
- [ ] 「上」「下」にすると、横長の帯になり、左から、検索／並べ方／見た目／ピン、ウインドウ、＋、グループの順に並ぶ。ステージは、帯を除いた残りになる
- [ ] 横長の帯の「一覧」は、ブラウザの横のタブのように並ぶ（少ないときは広く、多いときは狭く。収まらなければ横にスクロール）。「サムネイル」は高い帯、「アイコンの並び」は低い帯になる。どれも、大きさを大きくすると帯が高くなる（一覧は、タブも広くなる）
- [ ] 横長の帯でも、クリック・ダブルクリック・⌘＋クリック・右クリック・ステージへのドラッグ・グループへのドラッグが動く。横にドラッグして並べ替えると、入る位置に縦の線が出る
- [ ] 横長の帯のグループは、名前と中身のアイコンの小さな札で並ぶ（サムネイルの形式では、見本も出る）。右クリックのメニューの並べ替えは「左へ」「右へ」になる
- [ ] 横長の帯では、幅を変えるつまみは出ない（高さは形式で決まる）。形式・大きさを変えると高さが変わり、ステージのウインドウが並び直す
- [ ] 位置を変えると、前に出しているウインドウが新しい範囲に並び直し、新しい位置のウインドウバーの後ろに残ったウインドウが押し出される。前のウインドウバーの横にくっつけていたウインドウは、空いたところまで広がる
- [ ] どの辺でも、「常に出す」のとき、ウインドウを広げてもウインドウバーの後ろに入り込まない（上下では、縦いっぱいに広げたときに、もう一度ダブルクリックで元に戻る）
- [ ] どの辺でも、「自動で隠す」にすると、その端にポインタを寄せたときだけ出る。ほかの端では出ない
- [ ] 位置は、終了して起動し直しても残る。ディスプレイを 2 つつないでいるときは、どちらも同じ辺に出る

### Dock・メニューバーと同じ辺

- [ ] Dock を常に表示にして、同じ辺（左・下・右）にウインドウバーを置くと、ウインドウバーは Dock の内側に並び、重ならない
- [ ] 「上」に置くと、メニューバーのすぐ下に並ぶ
- [ ] Dock の位置・大きさ・自動で隠すかを変えると、ウインドウバーがそれに合わせて置き直され（遅くとも 2 秒ほどで）、ステージのウインドウも並び直す
- [ ] 常に表示の Dock と同じ辺で「自動で隠す」にして、Dock の上を通って画面の端までポインタを寄せると、ウインドウバーが出る。ポインタが Dock の上にある間は、出たり隠れたりを繰り返さない（上に置いたときの、メニューバーの上でも同じ）
- [ ] Dock を自動で隠す設定にして、同じ辺にウインドウバーを置くと、設定の「位置」の下に案内（オレンジの印と「Dock の設定を開く」）が出る。ほかの辺に変えるか、Dock を常に表示にして設定の画面に戻ると、案内が消える
- [ ] メニューバーを自動で隠す設定にして「上」に置くと、同じように案内が出る

## サムネイル

- [ ] 形式を「サムネイル」にすると、画面収録の許可を求められる。許可して開き直すと、ウインドウバーにウインドウの中身が映る
- [ ] ほかのウインドウに隠れているウインドウも、中身が映る。数秒で新しい中身に変わる
- [ ] 形式を「サムネイル」以外にすると、サムネイルを撮らない。許可がないまま「サムネイル」にすると、アイコンで出し、設定に案内が出る
- [ ] 許可がないときは、設定に案内と「画面収録を開く」が出る

## ほかのアプリとの重なり

- [ ] pinshot で「最前面に表示」にしたピンをウインドウバーの上へ動かすと、ピンがウインドウバーより上に出る（ウインドウバーを出し直しても、ピンの下に回る）
- [ ] 「最前面に表示しない」ピン・ふつうのウインドウは、これまでどおりウインドウバーの下に回る

## 仮想デスクトップ（操作スペース）

- [ ] デスクトップを 2 つ以上用意し、ウインドウバーの番号を押す。⌥Tab と同じ切り替え画面が、そのウインドウバーのディスプレイの真ん中に開き、押したデスクトップの最初のウインドウが選ばれている（見えるところまでスクロールしている）。開いた段階ではデスクトップも前面アプリも変わらない
- [ ] 同じアプリの異なるウインドウが別々の行に出る。行をクリックすると、別のデスクトップでもそのウインドウが前に出る。位置・大きさは変わらない
- [ ] Esc や画面の外のクリックで、選ばずに閉じられる。別の番号を押せば、そのデスクトップを選んで開き直す。空のデスクトップを押したときは、先頭が選ばれる
- [ ] まとめボタンを押すと、スイッチャーが先頭を選んだ状態で開く。1 列の細い帯でも、まとめボタンから開ける。「自動で隠す」でも、画面が開いている間はウインドウバーが隠れない
- [ ] 2 つのディスプレイで、それぞれのウインドウバーの番号を押すと、そのディスプレイの真ん中に開く。すべてのディスプレイのデスクトップが並び、ディスプレイの名前が見出しに出る。ほかのディスプレイのデスクトップのウインドウを選ぶと、そのウインドウが前に出る
- [ ] すべてのデスクトップに割り当てたウインドウには、切り替え画面でもウインドウバーと同じ印が付く（一覧は「すべて」、アイコンだけはアイコンの右下の角の丸い印、サムネイルは「すべて」）。下の名前にも「すべてのデスクトップ」と出る
- [ ] 「デスクトップボタンを表示」は初期設定ではオン。設定またはウインドウバーの見出し・余白の右クリックで切り替わり、再起動後も保持される。ウインドウやグループの行の右クリックは以前と同じ
- [ ] 「まとめ＋個別ボタン」では、左・右のバーでまとめボタンの下にデスクトップ別のボタンが縦に並ぶ。1 列まで狭めても番号のボタンで直接開ける。上・下のバーでは横に並ぶ
- [ ] 「まとめボタンのみ」にすると個別のボタンは消える。「自動」に戻すと、細い帯でだけまとめボタンが出る。並べ方の変更は右クリックと設定に反映され、再起動しても保持される
- [ ] ⌥Tab で、ウインドウバーのボタンを隠していても全デスクトップの一覧が開く。開いたディスプレイの現在のデスクトップが先頭で、矢印キーで移動して Enter で確定できる。画面収録の許可がなくても、アイコンと名前で選べる
- [ ] ⌥Tab で「まとめて表示」にすると最近使った順で、デスクトップの見出しがなくなる。別のデスクトップのウインドウには番号が付き、すべてのデスクトップに割り当てたウインドウは一度だけ出る
- [ ] ⌥Tab で開いた画面の右上の切り替えで、グループ分け（デスクトップ別／まとめて表示）と見た目（一覧／アイコンだけ／サムネイル）を、その場で変えられる。⌘G でグループ分け、⌘1・⌘2・⌘3 で見た目が変わる。変えても選んでいるウインドウはそのままで、見た目に合わせて画面の大きさが変わる（画面の真ん中のまま）
- [ ] 切り替え画面で選んだ表示は、次に ⌥Tab で開いたときも使われ、設定の「ウィンドウスイッチャー」にも同じ値が出る
- [ ] ウィンドウスイッチャー右上の「小・中・大」は、一覧の行とアイコン・格子のアイコン・サムネイルに反映される。切り替え後も選んだウインドウが見え、列数と矢印キーの移動が合う。設定でも同じ大きさが選ばれ、ウインドウバーのサイズは変わらない
- [ ] 画面収録の許可がないときに切り替え画面で「サムネイル」を選ぶと、許可を求められ、許可するまではアイコンだけで表示し、画面に「許可するまではアイコンだけで表示します」と出る
- [ ] 初めて使うときの切り替え画面は「デスクトップ別・アイコンだけ」
- [ ] 切り替え画面の高さは中身に合う（ウインドウが少ないとき、下が大きく空かない）。多いときは上限で止まり、スクロールできる
- [ ] 選んでいる項目は青い枠で囲まれる。デスクトップの見出しにウインドウの数が出る。下に操作の案内（↑↓←→ 選ぶ・↩ 開く・esc 閉じる・⌘G・⌘1〜3）が出る
- [ ] 初期設定の「キーを離す」では、⌥Tab で直前に使っていたウインドウが選ばれる。⌥ を押したまま Tab で次、⇧Tab で前へ（最後の次は最初）。⌥ を離すと選んでいるウインドウに切り替わる。⌥Tab をすばやく押して離すと、1 つ前のウインドウに戻る
- [ ] 右上の「確定」を「Enter」にすると、⌥Tab で開いて ⌥ を離しても前面ウインドウは変わらず、スイッチャーが残る。Tab・⇧Tab・矢印キー・もう一度 ⌥Tab で選べ、Enter やクリックで切り替わる。Esc では切り替えずに閉じる
- [ ] ⌥ を押したまま「キーを離す」から「Enter」に変えると、その回に ⌥ を離しても確定しない。「キーを離す」に戻す操作自体では確定せず、次の ⌥Tab から離して確定できる。選択した設定はアプリを再起動しても残り、設定画面にも反映される
- [ ] ウインドウバーのボタンから開いたときは、確定方法の設定にかかわらず、⌥ を離しても閉じず、Enter やクリックで決める
- [ ] 文字を打つと、ウインドウ名・アプリ名で絞り込まれる（ひらがな・カタカナ・英大小・全角半角を区別しない）。⌫ で 1 文字戻り、esc で絞り込みが消え（もう一度 esc で閉じる）、合うものがないときはその旨が出る
- [ ] スペースで選んだウインドウにチェックが付き、下に選んだ数が出る。↩ で、選んだウインドウだけがステージに並ぶ。ほかのデスクトップのウインドウは選べない（警告音）
- [ ] ⌘W で選んでいるウインドウを閉じ、⌘Q でアプリを終了、⌘M でしまう。一覧から消える（しまったものは薄く表示される）
- [ ] デスクトップ別のとき、数字キー 1〜9 で、そのデスクトップの最初のウインドウへ移る（見出しに「1 で移動」と出る）
- [ ] 切り替え画面は画面に合わせて大きく出る（幅は画面の 7 割まで）。アイコンの下にウインドウ名が出る。ステージに出ているウインドウには青い点が付く
- [ ] Slack・メールなど、Dock のアイコンにバッジ（赤い点・数）が出ているアプリは、ウインドウバーと切り替え画面のアイコンの右上にも同じバッジが出る。Dock のバッジが消えると、少しして（2 秒ほど）消える
- [ ] 書き出しに対応した Kickoff の作業中・回答待ち・未読の件数が、ウインドウバーとウィンドウスイッチャーの両方に出る。0 件や終了で消え、Kickoff を起動したまま Pinstage だけ再起動しても現在の数字が出る
- [ ] すべてのデスクトップに割り当てたウインドウの小さな印は、アイコンの右下に出て、右上のアプリのバッジと重ならない。アイコンだけのウインドウバーで最小化した場合も、印は残り、アイコンが薄くなる
- [ ] ウィンドウスイッチャーの「アイコンだけ」は各アイコンに名前を添える。格子の上下は同じ列を優先し、次のデスクトップの見出しをまたいで選べる。「サムネイル」は最初からアイコンと名前で選べ、撮れたものだけが画像に置き換わる
- [ ] 画面収録を許可しないと「サムネイル」を選んでもアイコンだけで開く。許可後はサムネイルに戻る。グループ分けと見た目は再起動後も別々に保持され、番号ボタンから開いたときも同じ表示になる

- [ ] デスクトップ 1 と 2 に別々のウインドウを開き、切り替えると、ウインドウバーにそのデスクトップのウインドウだけが並ぶ
- [ ] 起動した直後から、まだ見ていないデスクトップへ切り替えても、切り替えの動きの途中から、移った先のデスクトップの一覧が出ている（着いてから変わらない）

- [ ] Mission Control でデスクトップを足すと、少しして、そのデスクトップにもウインドウバーが出る。消したデスクトップのウインドウバーは残らない
- [ ] 同じアプリのウインドウを、同じ位置・同じ大きさで 2 つのデスクトップに置いても、それぞれのデスクトップで正しいほうだけが並ぶ（画面収録の許可がなくても）
- [ ] デスクトップ 1 と 2 を何度か行き来する（速く・ゆっくり・途中で指を止める）。どのときも、行き先のウインドウバーに前のデスクトップのウインドウが混ざらず、着いたあとに一覧が入れ替わらない
- [ ] 出ていくほうのウインドウバーも、スライドの途中で行が増えたり減ったりしない
- [ ] デスクトップ 2 でウインドウを開いてから 1 へ移り、また 2 へ戻ると、スライドの途中から、開いたウインドウが一覧に入っている
- [ ] 最小化したウインドウは、ほかのデスクトップのウインドウバーにも、スライドの途中から並んでいる
- [ ] サムネイルの見た目のとき、行き先のウインドウバーに、前に撮ったサムネイルがスライドの途中から出ている（着いたあとに撮り直す）
- [ ] フルスクリーンのアプリとデスクトップを行き来しても、デスクトップのウインドウバーに、フルスクリーンのウインドウの行が出たり消えたりしない
- [ ] 食い違ったときは、`~/Library/Logs/Pinstage/desktops.log`（Debug ビルドだけ）に、切り替えのときの記録が残っている
- [ ] トラックパッドで横にゆっくりスライドしている途中、前のデスクトップのウインドウバーは前のデスクトップと一緒に画面の外へ動き、行き先のデスクトップの上に残らない
- [ ] Mission Control を開いても、ウインドウバーがじゃまにならない（ウインドウバーの見え方を確かめる）
- [ ] フルスクリーンのアプリのデスクトップには、ウインドウバーが出ない
- [ ] 「自動で隠す」のとき、デスクトップを切り替えても、隠したウインドウバーがほかのデスクトップに付いてこない。左端に寄せると、いまのデスクトップのウインドウバーが出る
- [ ] ⌃⌥S・メニューの「ウインドウバーを出す・隠す」は、いまのデスクトップのウインドウバーだけに効く
- [ ] デスクトップを消したとき・ディスプレイをつなぎ直したときも、1 つのデスクトップにウインドウバーが 2 つ重ならない
- [ ] 最小化したウインドウ・隠したアプリ（⌘H）のウインドウは、どのデスクトップでも並ぶ。押すと、いまのデスクトップに出る
- [ ] 同じアプリのウインドウを、デスクトップ 1 と 2 に 1 枚ずつ置いたとき、それぞれのデスクトップで正しいほうだけが並ぶ（画面収録の許可がないときは、同じ位置・同じ大きさだと取り違えることがある）
- [ ] いまのデスクトップのウインドウだけを並べているときにドラッグで並べ替えても、ほかのデスクトップに戻ったとき、そちらの並びが崩れていない
- [ ] ウインドウバーの通常の一覧は、いまのデスクトップ・そのディスプレイのまま。ほかのデスクトップのボタンで別の一覧を開いても、通常の一覧は入れ替わらない
- [ ] しまってある（最小化した）ほかのデスクトップのウインドウの行には、重なった四角と番号の印が出る。押すと、そのデスクトップへ移って、そのウインドウが前に出る
- [ ] Dock の「割り当て先」で「すべてのデスクトップ」にしたアプリのウインドウは、どのデスクトップのウインドウバーにも並び、行に重なった四角と「すべて」の印が出る（上下の帯では絵だけ。アイコンの並びでは、アイコンの右上の角に小さな丸い印）。ポインタを乗せると「すべてのデスクトップに割り当てたウインドウです」と出る。番号の印は出ない
- [ ] 割り当てを「なし」に戻すと、少しして印が消え、そのウインドウのあるデスクトップのウインドウバーだけに並ぶ
- [ ] 起動した直後に、まだ見ていないデスクトップへ移っても、そのデスクトップのウインドウバーに、そこのウインドウが並んでいる
- [ ] 検索では、ほかのデスクトップのウインドウも見つかる。グループの呼び出しにも使われる
- [ ] 「次のウインドウ」「前のウインドウ」は、いまのデスクトップのウインドウの中で切り替わる

## 複数のディスプレイ

- [ ] ディスプレイを 2 つつなぐと、それぞれの左端にウインドウバーが出る
- [ ] それぞれのウインドウバーに、そのディスプレイにあるウインドウだけが並ぶ（2 つにまたがるウインドウは、多く重なっているほう）
- [ ] それぞれのバーのまとめ・個別ボタンから、そのディスプレイのデスクトップを選べる。「メインのディスプレイだけ」では、同じ番号の別画面のデスクトップを区別して選べる。デスクトップを全ディスプレイで共有するときは、同じデスクトップのボタンが重複しない
- [ ] ウインドウを手でほかのディスプレイへ動かすと、数秒でそちらのウインドウバーへ移る。行をほかのディスプレイのステージへドラッグしたときも、そちらへ移る
- [ ] 行をバーの外へドラッグすると、ウインドウのアイコンと名前がポインタに付いて動く。別のディスプレイへ渡っても途切れず、そのディスプレイのウインドウバーに重ねると枠が光る。離すと見本と枠が消え、ウインドウが移る
- [ ] 元のバーへ戻ると見本は消え、普段どおり並べ替えの線が出る。ディスプレイの境界を越えたときは、元のバーのすぐ近くでも並べ替えにならない。一覧・アイコン 1 列・サムネイル・上下の帯と、複数枚のまとまりでも確かめる
- [ ] 「自動で隠す」で、ドラッグ中に別のディスプレイの端で止まる。行き先のバーが出たら、ポインタを動かし直さなくても枠が光る
- [ ] グループは、保存したディスプレイ（編集画面の「ディスプレイ」）のウインドウバーにだけ並ぶ。右のディスプレイのウインドウバーで保存したグループは、右のウインドウバーに並ぶ
- [ ] 編集画面でディスプレイを「ポインタのあるディスプレイ」にしたグループは、どのウインドウバーにも並ぶ
- [ ] グループを保存したディスプレイを外すと、そのグループはメインのディスプレイのウインドウバーに並ぶ（「つながっていないディスプレイ」と出る）
- [ ] 片方のウインドウバーでグループを並べ替えても（ドラッグ・上へ・下へ）、もう片方のグループの並びが崩れない。ショートカットの番号は全体の並び順のまま（飛び飛びになることがある）
- [ ] ほかのディスプレイ・デスクトップのグループがあるとき、グループのないウインドウバーには「このデスクトップのグループはありません」と出る
- [ ] デスクトップ 1 で保存したグループは、デスクトップ 1 のウインドウバーにだけ並び、デスクトップ 2 のウインドウバーには並ばない（「見えている画面を記録」・ショートカット・メニューで保存したときも）
- [ ] グループの右クリック →「出すデスクトップ」で、「このデスクトップだけ（デスクトップ 2）」「すべてのデスクトップ」のいまの選択に印が付く。「すべてのデスクトップ」にすると、ほかのデスクトップのウインドウバーにも並び、「このデスクトップだけ」にすると、ほかのデスクトップから消える
- [ ] 前の版で保存したグループは、すべてのデスクトップに並ぶ
- [ ] Mac を再起動したあとも、グループは保存したデスクトップのウインドウバーに並んだまま
- [ ] グループを保存したデスクトップを Mission Control で消すと、そのグループはどのデスクトップにも並ぶ
- [ ] デスクトップごとに並べ替えても、ほかのデスクトップのグループの並びは崩れない（ショートカットの番号は全体の並び順）
- [ ] 「メインのディスプレイだけ」のときは、すべてのウインドウ・グループが並ぶ
- [ ] 片方のウインドウバーで並べ替えても、もう片方の並びが崩れない
- [ ] 「次のウインドウ」「前のウインドウ」は、ポインタのあるディスプレイのウインドウの中で切り替わる
- [ ] 2 つ目のディスプレイのウインドウバーで選ぶと、2 つ目のディスプレイに並ぶ（1 つ目のディスプレイのステージはそのまま）
- [ ] Dock などから 2 つ目のディスプレイにある組み合わせ外のウインドウを前に出すと、2 つ目のウインドウバーだけで選択が切り替わる。「メインのディスプレイだけ」の設定では、メインのバーに青い枠が付く
- [ ] 1 つ目の前に出しているウインドウを 2 つ目で選ぶと、2 つ目へ移り、1 つ目の行の枠が消える
- [ ] 並べ方は、ディスプレイごとに別々に選べる
- [ ] 設定で「メインのディスプレイだけ」にすると、ウインドウバーが 1 つになる
- [ ] ディスプレイを外す・つなぐと、ウインドウバーが作り直される

## 型の編集画面

- [ ] 並べ方のメニュー →「新しい型…」で編集画面が開き、Dock にアイコンが出る（閉じると消える）
- [ ] 枠をドラッグで動かすとき・角で大きさを変えるとき、ポインタにぴったり付いてくる（震えない）
- [ ] 枠をドラッグで動かせる。選んだ枠の 4 つの角で大きさを変えられる。重ねても、間を空けてもよい
- [ ] 「目盛りに合わせる」をオフにすると、細かく動かせる
- [ ] 「最前面へ」「最背面へ」で番号（前後の順番）が変わる
- [ ] 「ひな形から始める」に「左右に並べる」「上下に並べる」「4 分割」「6 分割」「左を大きく」「重ねる」の順に並び（前の 5 つは並べ方のメニューと同じ順・同じ名前）、選ぶと枠が置き換わる
- [ ] 保存すると、並べ方のメニューと設定の「型」のタブに出る。その型で並べているウインドウは並び直す
- [ ] 「いまの並びから型を作る…」で、ステージのウインドウの並びから編集を始められる
- [ ] 設定の「型」のタブで、編集・名前の変更・複製・削除ができる

## 検索

- [ ] ⌃⌥Space で、ポインタのあるディスプレイの真ん中より少し上に検索の欄が出て、すぐ文字を打てる。前面のアプリのフォーカスは外れない
- [ ] ウインドウバーの「ウインドウ」の見出しの🔍・メニューバーの「検索…」でも出る
- [ ] 何も打たないと、グループとウインドウがすべて並ぶ。打つと、ウインドウ名・アプリ名・グループ名で絞り込まれる（空白で区切ると、すべてを含むものだけ）
- [ ] 「ＳＡＦＡＲＩ」「さふぁり」のように、全角・ひらがなで打っても見つかる（カタカナ・半角の名前のもの）
- [ ] ↑↓ で選び、↩ でウインドウだけが出る（グループなら呼び出す）。⌘↩ でステージに足す
- [ ] 検索の欄を開いたまま数秒待っても、選んでいる行がずれない
- [ ] 日本語入力で変換している途中の ↩・↑↓ は、変換の確定・候補選びに使われる（結果を出してしまわない）
- [ ] esc・ほかをクリック・もう一度 ⌃⌥Space で閉じる
- [ ] 出す先は、検索の欄を開いたときにポインタがあったディスプレイ

## 自動化

- [ ] 「ショートカット」アプリで「Pinstage」を探すと、「グループを呼び出す」「ウインドウバーを出す・隠す」「ステージをグループとして保存」「ウインドウ・グループを検索」が出る
- [ ] 「グループを呼び出す」でグループを一覧から選べ、動かすとそのグループが並ぶ。グループを足す・名前を変えると、一覧も変わる
- [ ] 「ウインドウバーを出す・隠す」で、出す・隠す・切り替えるが選べて、そのとおりに動く
- [ ] 「ステージをグループとして保存」で、名前を付けて保存できる（空なら仮の名前）。ステージが空なら、理由が出る
- [ ] Pinstage を終了しているときに「ショートカット」から動かすと、Pinstage が起動して動く
- [ ] Pinstage を終了しているときに `open "pinstage://group/グループ 1"` を流すと、起動してそのグループが並ぶ
- [ ] オートメーション（例: 特定のアプリを開いたとき）で「グループを呼び出す」が動く
- [ ] ターミナルで `open "pinstage://group/グループ 1"` を流すと、そのグループが並ぶ。`open pinstage://strip/hide`・`open pinstage://search`・`open "pinstage://save?name=テスト"` も動く
- [ ] 設定の「自動化」に、グループごとの URL と、そのほかの操作の URL が並び、コピーのボタンでコピーできる

## ショートカットの変更

- [ ] 設定 →「ショートカット」で、ボタンを押してからキーを押すと割り当てられ、すぐに効く
- [ ] ほかの操作と同じキーを割り当てると、前の操作から外れたことが出る
- [ ] ⌘・⌥・⌃ のどれもないキーは割り当てられない。esc でやめられる
- [ ] 記録している途中で設定のウインドウを閉じても、ほかのショートカット（⌃⌥S など）が効く
- [ ] × で外すと効かなくなる。「すべて初期設定に戻す」で ⌃⌥1〜9・⌃⌥S に戻る
- [ ] 「グループ」の欄の「n 番目のグループを呼び出す」の後ろに、いまその番号にあるグループの名前が薄く出る（グループを並べ替えると変わる）
- [ ] 変えたキーが、ウインドウバーのグループの行とメニューバーのメニューに出る
- [ ] 終了して起動し直しても、割り当てが残る
- [ ] ⌃⌥] / ⌃⌥[ で、最後に呼び出したグループの次・前のグループが出る（端まで行ったら反対の端へ）
- [ ] 「次のウインドウを出す」「前のウインドウを出す」にキーを割り当てると、ポインタのあるディスプレイで、ウインドウバーの並びの次・前のウインドウだけが出る
