# 手で確かめること

画面の操作は自動のテストで確かめにくいので、変えたところに関係する項目を、`make run` で起動して手で確かめます。

## 起動と許可

- [ ] 設定 →「一般」の「ログイン時に起動」をオンにすると、システム設定の「ログイン項目」に Pinstage が入る（許可が要るときは案内が出る）。ログインし直すと起動する
- [ ] macOS のステージマネージャをオンにすると、数秒でストリップに案内が出る（× で、この起動の間は閉じられる）。設定の「一般」にも「オフにする」が出る。オフにすると案内が消える

- [ ] 初めて起動すると、アクセシビリティの許可を求められる。許可するまで、ストリップに案内が出る
- [ ] 許可すると、数秒でストリップにウインドウが並ぶ（起動し直さなくてよい）
- [ ] メニューバーにアイコンが出て、Dock には出ない

## ステージ

- [ ] ストリップの行をクリックすると、そのウインドウが最前面に出る（大きさは変わらず、ストリップと重なるところだけ右へずれる）
- [ ] 設定の「1 枚だけ出すときの大きさ」を「縦いっぱい」にすると、1 つだけクリックしたウインドウが、幅はそのまま縦いっぱいになる。「そのまま」「ステージいっぱい」もそのとおりになる
- [ ] Safari を 2 枚、Finder を 2 枚開いて、Safari と Finder を 1 枚ずつ ⌘＋クリックで並べたとき、選んでいないもう 1 枚が前に出てこない
- [ ] しまってあった（最小化した）ウインドウをクリックすると、戻ったあと正しい位置・大きさに並ぶ
- [ ] 別の操作スペースに移って戻っても、ステージの選択とストリップの並び順が崩れない
- [ ] 行をダブルクリックすると、そのウインドウだけがステージいっぱい（常に出すときはストリップの右側いっぱい）に広がって前に出る
- [ ] ⌘＋クリックで 2 つ目を足すと、2 つが左右に並んで最前面に出る
- [ ] もう一度 ⌘＋クリックすると、ステージから外れ、残りが並び直す
- [ ] 行をストリップの外（右）へドラッグして離すと、ステージに足される
- [ ] 行をストリップの中で上下にドラッグすると、落とす位置に青い線が出る。離すとその位置へ移る（自分のすぐ上・すぐ下では線が出ない）
- [ ] 並べ替えたあとにウインドウを開け閉めしても、並び順が保たれる（新しいウインドウは先頭に入る）
- [ ] 並べ替えてから Pinstage を終了し、起動し直すと、同じ並び順に戻る（止めている間に開いたウインドウは先頭に入る）
- [ ] しまってある（最小化した）ウインドウも、出すと元に戻って並ぶ
- [ ] ステージに出しているウインドウの行は、色の付いた枠で分かる
- [ ] 違うアプリのウインドウを組み合わせても、すべて最前面に出る
- [ ] 行の右クリック →「ウインドウを閉じる」で閉じる。保存していない書類なら、アプリが保存するかを聞く。閉じたら行が消える
- [ ] 行の右クリック →「〇〇を終了」でアプリが終了し、そのアプリの行がすべて消える
- [ ] ステージに出している行の右クリック →「ステージから外す」で外れ、残りが並び直す

## 並べ方

- [ ] 並べ方を「左を大きく」「上下に並べる」「重ねる」に変えると、その場で並び直す
- [ ] 「余白を空ける」をオンにすると、ウインドウの間と画面の端が空く
- [ ] ウインドウを手で動かし（重ねたり、間を空けたり）、「いまの並びを型として登録」すると、並べ方のメニューに「マイ型 1」が出る
- [ ] 別のウインドウを選んで「マイ型 1」にすると、同じ形で並ぶ
- [ ] 登録した型の名前を変える・削除できる。削除した型を使っていたグループは「自動（均等）」になる

## グループ

- [ ] 「グループとして保存」で、グループに「グループ 1」が並ぶ
- [ ] 別のウインドウを出したあとグループを押すと、保存した組み合わせと並べ方で出る
- [ ] ⌃⌥1 で 1 番目のグループが出る
- [ ] グループの右クリックで、名前を変える・並べ替える・削除できる
- [ ] グループの右クリック →「編集…」で編集画面が開く。名前・中身（ウインドウを足す・− で外す・ドラッグで並べ替え）・並べ方・余白・ディスプレイを変えて保存すると、ストリップの見本と、呼び出したときの並びが変わる
- [ ] 別の組み合わせをステージに出して、グループの右クリック →「いまのステージで上書き保存」で中身が入れ替わる（名前と並び順はそのまま）

### 見えている画面を記録

- [ ] ウインドウを手で動かして重ねたり大きさを変えたりしたあと、「ステージ」の欄のカメラのボタンを押すと、見えているウインドウがすべて入ったグループが増える。見本が、いまの画面と同じ形・重なりになる
- [ ] 最小化したウインドウ・隠したアプリ（⌘H）のウインドウ・ほかのデスクトップのウインドウ・ほかのディスプレイのウインドウは入らない
- [ ] ウインドウを動かしたあと、そのグループを押すと、記録したときの位置・大きさ・重なりの順番に戻る。並べ方の欄が「記録した配置」になり、余白のボタンは押せない
- [ ] 並べ方のメニューでほかの型を選ぶと、そちらで並び直る（記録した配置の印は消える）
- [ ] メンバーのアプリを 1 つ終了してから呼び出すと、起動し直して記録した枠に置く。起動できなかったときも、ほかのウインドウの枠はずれない
- [ ] グループの右クリック →「見えている画面で上書き記録」で、いまの見た目に入れ替わる（名前と並び順はそのまま）
- [ ] 細い帯（アイコンの並びを 1 列まで狭めたとき）でも、保存のボタンの下にカメラのボタンがある
- [ ] 設定の「ショートカット」で「見えている画面をグループとして記録」を割り当てると、ポインタのあるディスプレイの画面を記録する（初期設定は割り当てなし）
- [ ] 編集画面で、記録したグループの並べ方が「記録した配置」と出る。ほかの型に変えて保存すると、そちらになる
- [ ] ウインドウの行をグループの行の上へドラッグすると、グループの行が光り、離すとそのグループに足される（見本にアイコンが増える）。もう入っているウインドウなら何も変わらない
- [ ] ウインドウの行をグループの上へドラッグしている間は、並べ替えの線が出ない。グループの外で離すと、これまでどおり並べ替え・ステージに足すになる
- [ ] グループの見本のアイコンを、グループの行の外へドラッグすると「−」の印が出て、離すとそのグループから外れる
- [ ] 見本のアイコンをほかのグループの行の上へドラッグすると、その行が光り、離すとそちらへ移る
- [ ] 並びの見本（中・大）で、アイコンを同じグループのほかのアイコンの上へドラッグすると、そのアイコンが光り、離すと 2 つの場所が入れ替わる。呼び出したときの並びも入れ替わる
- [ ] 細い帯の 2×2 でも入れ替わる。「アイコンの並び」の横 1 列では、離したアイコンの位置へ差し込まれる
- [ ] 同じグループの中の、アイコンのないところで離したときは、何も変わらない
- [ ] 最後の 1 つを外そうとすると、グループごと削除するか聞かれる。移して空になったときも、削除するか聞かれる
- [ ] 見本のアイコンをクリックしただけ（動かさない）なら、グループを呼び出す。グループの行のドラッグでの並べ替えも、これまでどおりできる
- [ ] 見た目が「アイコンの並び」（横 1 列）・細い帯（2×2）でも、アイコンをドラッグして外す・移すができる
- [ ] グループの欄をスクロールして隠れた行の位置で離しても、そのグループには入らない
- [ ] グループを 10 個くらい作っても、グループの欄だけがスクロールし、ウインドウの一覧が潰れない
- [ ] グループの行を上下にドラッグして並べ替えられる。ショートカットの番号も並びに合わせて変わり、起動し直しても残る。動かさずに離すとグループを呼び出す
- [ ] グループの行に、呼び出したときの並びの見本が出る（枠ごとに入るアプリのアイコン。並べ方・余白・登録した型に合わせた形）
- [ ] 起動していないアプリのアイコンは薄く出る。ポインタを乗せると、中身の一覧（番号・アプリ・ウインドウの名前）が出る
- [ ] 大きさが「小」のときは、見本の代わりにアプリのアイコンが並ぶ
- [ ] グループの右クリック →「グループのアプリを終了…」で、アプリの名前つきの確認が出る。「終了」で中のアプリが終了する（Finder は終了しない）。中のアプリがどれも動いていなければ選べない
- [ ] Pinstage を終了して起動し直しても、グループと型が残っている
- [ ] グループの中のアプリを終了してからグループを押すと、アプリが起動し、ウインドウが出てから並ぶ
- [ ] ディスプレイを 2 つつないだとき、保存したときのディスプレイに並ぶ（ストリップのないディスプレイでは画面いっぱいを使う）

## ストリップ

- [ ] いちばん上の帯に「🔍 検索 ⌃⌥Space」・見た目・ピンが並ぶ。幅を狭めると、検索は「検索」だけ→虫めがねだけに縮み、見出しの文字が縦に折り返さない
- [ ] アイコンのボタンは同じ大きさで、ポインタを乗せると背景が出る。ピンは押すたびに「常に出す」「自動で隠す」が入れ替わる（常に出すときは青）
- [ ] 「ウインドウ」「グループ」「ステージ」の見出しに数が出る
- [ ] ウインドウ・グループの行は、ポインタを乗せると少し明るくなる。ステージに出しているウインドウは青い枠
- [ ] 「ステージ」の欄に、並べ方の欄（押すとメニュー）と余白のボタンが 1 行に並び、その下の「グループとして保存」が青い（ストリップを押していなくても灰色にならない）。ステージが空なら押せない
- [ ] 幅を狭めると「グループとして保存」→「グループに保存」→「保存」と短くなり、途中で切れない
- [ ] 細い帯（アイコンの並びを狭めたとき）では、上に検索・見た目・ピン、下に並べ方・余白・保存のアイコンが縦に並ぶ

- [ ] メニューバー →「自動で隠す」（または設定の「出し方」）にすると、ストリップが、置いている辺の外へ隠れる。画面のその端にポインタを寄せると出て、離れると隠れる
- [ ] 「自動で隠す」のときは、ステージが画面いっぱいになる
- [ ] 枠を自前で描くアプリ（Kickoff など Electron のアプリ）のウインドウも、ストリップに並ぶ。パネル・ツールチップ・メニューは並ばない

## ストリップの後ろに入り込ませない（「常に出す」のとき）

- [ ] ウインドウのタイトルバーをダブルクリックすると、ストリップの右側いっぱいに広がる（ストリップの後ろに入り込まない）。もう一度ダブルクリックすると、元の大きさ・位置に戻る
- [ ] 緑のボタン（option を押しながら＝拡大）・ウインドウ メニューの「フィル」でも、ストリップの右側に収まる
- [ ] ウインドウをドラッグしてストリップの後ろへ入れると、ドラッグしている間はそのまま、離すとストリップの右側へずれる
- [ ] Safari・Finder・ターミナル・Xcode など、いくつかのアプリで同じように効く（知らせを出さないアプリでも、1〜2 秒で戻る）
- [ ] その大きさより小さくできないアプリでも、何度も動かそうとしてちらつかない
- [ ] 設定の「ストリップの後ろにウインドウを入り込ませない」をオフにすると、入り込んでも戻さない。「自動で隠す」のときは、この設定は選べず、戻さない
- [ ] ⌃⌥S でストリップを隠している間は戻さない。出し直すと、入り込んでいたウインドウが右へずれる
- [ ] ストリップの右の縁をドラッグして広げると、離したすぐあとに、新しい幅の後ろに入ったウインドウが右へずれる。ステージに出しているウインドウも、新しい幅で並び直る。ダブルクリックで広げたときも、新しい幅の右側いっぱいになる
- [ ] 狭めたときは、ストリップの横にくっつけていたウインドウが、新しい幅の右端まで広がる（右端はそのまま）。離れたところにあるウインドウは動かない
- [ ] 狭めたあと、ウインドウのタイトルバーをダブルクリックすると、新しい幅の右側いっぱいに広がる（前の幅のぶんの余白が残らない）
- [ ] 幅を変えたあと Pinstage を開き直しても、同じ幅で出る
- [ ] ストリップの上の帯のピンを押すと、「常に出す」と「自動で隠す」が入れ替わる（細い帯のときも、上の帯のピン）
- [ ] ピンで「自動で隠す」に変えても、ポインタがストリップの上にある間は隠れず、離れると隠れる
- [ ] ⌃⌥S で、ストリップを出す・隠すを切り替えられる
- [ ] 「自動で隠す」で ⌃⌥S を押すと、ストリップが出たままになる（すぐ閉じない）。ポインタを一度ストリップに入れて離すと隠れる。もう一度 ⌃⌥S でも隠れる
- [ ] ディスプレイを左右に並べ「自動で隠す」にしたとき、左のディスプレイの上で右のディスプレイのストリップがちらつかない
- [ ] 行を別のディスプレイへドラッグして離すと、そのディスプレイのステージに足される
- [ ] ストリップの見出しの見た目のボタン（または設定の「形式」）で、アイコンの並び・一覧・サムネイルの 3 つを選べる
- [ ] 「たたむ」のボタン・メニュー・設定・ショートカットは、もうない（細い帯にしたいときは、アイコンの並びを狭める）
- [ ] 見た目のメニューの「大きさ」（または設定の「大きさ」）で、小・中・大を切り替えられる。どの形式にもかかる（初期設定は小。前にアイコンの並びの大きさを選んでいたら、その大きさになっている）
- [ ] 「一覧」で大きくすると、行の高さ・アイコン・名前の文字が大きくなる。「小」は、いままでどおりブラウザの縦のタブと同じくらい
- [ ] 「サムネイル」で大きくすると、ウインドウが多くても、サムネイルが大きいまま並ぶ（収まらなければスクロール）。左下のアプリのアイコンと名前の文字も大きくなる
- [ ] 「アイコンの並び」で大きくすると、アイコンが大きくなり、1 行に入る数が減る。1 列のときの幅も広がる（小 52pt・中 58pt・大 64pt）
- [ ] 前に「細い帯」にしていたら、「アイコンの並び」になっている
- [ ] 前に「一覧・1 行」「一覧・2 行」にしていたら「一覧」、「サムネイル・中」「サムネイル・大」にしていたら「サムネイル」になっている
- [ ] 「一覧」は、ブラウザの縦のタブと同じくらいの大きさの 1 行（アイコンと名前）で並ぶ。ウインドウの数を変えても、行の高さは変わらない。多いときはスクロールする
- [ ] 一覧の行にポインタを乗せると、ウインドウの名前のすべてと、アプリの名前が出る
- [ ] 「サムネイル」で、ウインドウが少ないほど・ストリップが広いほど、サムネイルが大きくなる
- [ ] 「アイコンの並び」で、ステージの側の縁をドラッグして狭めていくと、列が減り、最後は 1 列の細い帯になる（それより狭くはならない。小 52pt・中 58pt・大 64pt）。途中で、上の帯と並べ方のボタンが、アイコンだけの縦並びに切り替わる（ドラッグしている間にも切り替わる）。「常に出す」なら、離したあとにステージが広がって並び直す
- [ ] 細い帯でも、クリック・ダブルクリック・⌘＋クリック・ドラッグ・右クリックがほかの形式と同じに動く。ポインタを乗せるとウインドウの名前が出る
- [ ] 細い帯のグループは中身のアイコンが 2×2 で並び、下にショートカットが出る。並べ方・余白・グループとして保存はアイコンのボタンで使える
- [ ] アイコンの並びを狭めたあと「一覧」「サムネイル」に切り替えると、一覧の幅（前に変えた幅）で出る。「アイコンの並び」に戻すと、狭めた幅に戻る。起動し直しても、どちらの幅も残る
- [ ] 一覧・サムネイルは、いままでどおり 160pt より狭くはならない
- [ ] 「アイコンの並び」にすると、ウインドウがアイコンだけの並びになる。ストリップの幅に入るだけ 1 行に並び、名前はポインタを乗せると出る。もう一度押すと一覧に戻る
- [ ] アイコンの並びでも、クリック・ダブルクリック・⌘＋クリック・右クリック・ステージへのドラッグが動く。縦横にドラッグして並べ替えると、入る位置に縦の線が出る
- [ ] アイコンの並びのときは、サムネイルを撮らない（一覧に戻すと、また映る）
- [ ] 「サムネイル」でウインドウが少ないときは、行が大きくなってストリップの縦いっぱいに並ぶ。多いときは、いつもの大きさのままスクロールできる
- [ ] 設定の「並べる数」より多いウインドウは、「ほかのウインドウ（n）」にたたまれる
- [ ] ストリップを押しても、前面のアプリのフォーカスが外れない
- [ ] 左のストリップの右の縁（右のストリップなら左の縁）にポインタを乗せると、左右の矢印のポインタになり縁が光る。ドラッグすると幅が変わる（狭すぎ・広すぎにはならない）
- [ ] 「常に出す」で幅を変え終えると、ステージのウインドウが新しい幅に合わせて並び直す。ほかのディスプレイのストリップも同じ幅になる
- [ ] 「自動で隠す」で幅を変えても、ドラッグを終えた瞬間に隠れない
- [ ] 終了して起動し直しても、幅が残る

## ストリップの位置（上下左右）

設定の「位置」か、ストリップの見出しの見た目のボタン →「位置」で切り替える。

- [ ] 「右」にすると、ストリップが右端に縦長で出て、ステージはその左側になる。幅を変えるつまみは左の縁に出て、左へドラッグすると広がる
- [ ] 「上」「下」にすると、横長の帯になり、左から、検索／見た目／ピン、ウインドウ、グループ、並べ方・余白・保存・記録の順に並ぶ。ステージは、帯を除いた残りになる
- [ ] 横長の帯の「一覧」は、ブラウザの横のタブのように並ぶ（少ないときは広く、多いときは狭く。収まらなければ横にスクロール）。「サムネイル」は高い帯、「アイコンの並び」は低い帯になる。どれも、大きさを大きくすると帯が高くなる（一覧は、タブも広くなる）
- [ ] 横長の帯でも、クリック・ダブルクリック・⌘＋クリック・右クリック・ステージへのドラッグ・グループへのドラッグが動く。横にドラッグして並べ替えると、入る位置に縦の線が出る
- [ ] 横長の帯のグループは、名前と中身のアイコンの小さな札で並ぶ（サムネイルの形式では、見本も出る）。右クリックのメニューの並べ替えは「左へ」「右へ」になる
- [ ] 横長の帯では、幅を変えるつまみは出ない（高さは形式で決まる）。形式・大きさを変えると高さが変わり、ステージが並び直す
- [ ] 位置を変えると、ステージに出しているウインドウが新しい範囲に並び直し、新しい位置のストリップの後ろに残ったウインドウが押し出される。前のストリップの横にくっつけていたウインドウは、空いたところまで広がる
- [ ] どの辺でも、「常に出す」のとき、ウインドウを広げてもストリップの後ろに入り込まない（上下では、縦いっぱいに広げたときに、もう一度ダブルクリックで元に戻る）
- [ ] どの辺でも、「自動で隠す」にすると、その端にポインタを寄せたときだけ出る。ほかの端では出ない
- [ ] 位置は、終了して起動し直しても残る。ディスプレイを 2 つつないでいるときは、どちらも同じ辺に出る

### Dock・メニューバーと同じ辺

- [ ] Dock を常に表示にして、同じ辺（左・下・右）にストリップを置くと、ストリップは Dock の内側に並び、重ならない
- [ ] 「上」に置くと、メニューバーのすぐ下に並ぶ
- [ ] Dock の位置・大きさ・自動で隠すかを変えると、ストリップがそれに合わせて置き直され（遅くとも 2 秒ほどで）、ステージのウインドウも並び直す
- [ ] 常に表示の Dock と同じ辺で「自動で隠す」にして、Dock の上を通って画面の端までポインタを寄せると、ストリップが出る。ポインタが Dock の上にある間は、出たり隠れたりを繰り返さない（上に置いたときの、メニューバーの上でも同じ）
- [ ] Dock を自動で隠す設定にして、同じ辺にストリップを置くと、設定の「位置」の下に案内（オレンジの印と「Dock の設定を開く」）が出る。ほかの辺に変えるか、Dock を常に表示にして設定の画面に戻ると、案内が消える
- [ ] メニューバーを自動で隠す設定にして「上」に置くと、同じように案内が出る

## サムネイル

- [ ] 形式を「サムネイル」にすると、画面収録の許可を求められる。許可して開き直すと、ストリップにウインドウの中身が映る
- [ ] ほかのウインドウに隠れているウインドウも、中身が映る。数秒で新しい中身に変わる
- [ ] 形式を「サムネイル」以外にすると、サムネイルを撮らない。許可がないまま「サムネイル」にすると、アイコンで出し、設定に案内が出る
- [ ] 許可がないときは、設定に案内と「画面収録を開く」が出る

## ほかのアプリとの重なり

- [ ] pinshot で「最前面に表示」にしたピンをストリップの上へ動かすと、ピンがストリップより上に出る（ストリップを出し直しても、ピンの下に回る）
- [ ] 「最前面に表示しない」ピン・ふつうのウインドウは、これまでどおりストリップの下に回る

## 仮想デスクトップ（操作スペース）

- [ ] デスクトップ 1 と 2 に別々のウインドウを開き、切り替えると、ストリップにそのデスクトップのウインドウだけが並ぶ
- [ ] 起動した直後から、まだ見ていないデスクトップへ切り替えても、切り替えの動きの途中から、移った先のデスクトップの一覧が出ている（着いてから変わらない）
- [ ] 起動したとき、いまのデスクトップに、ほかのデスクトップのストリップがちらっと出ない
- [ ] Mission Control でデスクトップを足すと、少しして、そのデスクトップにもストリップが出る。消したデスクトップのストリップは残らない
- [ ] 同じアプリのウインドウを、同じ位置・同じ大きさで 2 つのデスクトップに置いても、それぞれのデスクトップで正しいほうだけが並ぶ（画面収録の許可がなくても）
- [ ] デスクトップ 1 と 2 を何度か行き来する（速く・ゆっくり・途中で指を止める）。どのときも、行き先のストリップに前のデスクトップのウインドウが混ざらず、着いたあとに一覧が入れ替わらない
- [ ] 出ていくほうのストリップも、スライドの途中で行が増えたり減ったりしない
- [ ] デスクトップ 2 でウインドウを開いてから 1 へ移り、また 2 へ戻ると、スライドの途中から、開いたウインドウが一覧に入っている
- [ ] 最小化したウインドウは、ほかのデスクトップのストリップにも、スライドの途中から並んでいる
- [ ] サムネイルの見た目のとき、行き先のストリップに、前に撮ったサムネイルがスライドの途中から出ている（着いたあとに撮り直す）
- [ ] フルスクリーンのアプリとデスクトップを行き来しても、デスクトップのストリップに、フルスクリーンのウインドウの行が出たり消えたりしない
- [ ] 食い違ったときは、`~/Library/Logs/Pinstage/desktops.log`（Debug ビルドだけ）に、切り替えのときの記録が残っている
- [ ] トラックパッドで横にゆっくりスライドしている途中、前のデスクトップのストリップは前のデスクトップと一緒に画面の外へ動き、行き先のデスクトップの上に残らない
- [ ] Mission Control を開いても、ストリップがじゃまにならない（ストリップの見え方を確かめる）
- [ ] フルスクリーンのアプリのデスクトップには、ストリップが出ない
- [ ] 「自動で隠す」のとき、デスクトップを切り替えても、隠したストリップがほかのデスクトップに付いてこない。左端に寄せると、いまのデスクトップのストリップが出る
- [ ] ⌃⌥S・メニューの「ストリップを出す・隠す」は、いまのデスクトップのストリップだけに効く
- [ ] デスクトップを消したとき・ディスプレイをつなぎ直したときも、1 つのデスクトップにストリップが 2 つ重ならない
- [ ] 最小化したウインドウ・隠したアプリ（⌘H）のウインドウは、どのデスクトップでも並ぶ。押すと、いまのデスクトップに出る
- [ ] 同じアプリのウインドウを、デスクトップ 1 と 2 に 1 枚ずつ置いたとき、それぞれのデスクトップで正しいほうだけが並ぶ（画面収録の許可がないときは、同じ位置・同じ大きさだと取り違えることがある）
- [ ] いまのデスクトップのウインドウだけを並べているときにドラッグで並べ替えても、ほかのデスクトップに戻ったとき、そちらの並びが崩れていない
- [ ] 設定の「ほかのデスクトップのウインドウも出す」をオンにすると、起動した直後から（まだ見ていないデスクトップのものも）、すべてのデスクトップのウインドウが並ぶ。オフに戻すと、すぐいまのデスクトップだけになる
- [ ] オンのとき、ほかのデスクトップのウインドウの行に重なった四角と番号の印が出る。いまのデスクトップのウインドウには出ない
- [ ] ほかのデスクトップのウインドウの行を押すと、そのデスクトップへ移って、そのウインドウが前に出る（同じアプリのウインドウがいまのデスクトップにあっても）
- [ ] 起動した直後に、まだ見ていないデスクトップへ移っても、そのデスクトップのストリップに、そこのウインドウが並んでいる
- [ ] 検索では、ほかのデスクトップのウインドウも見つかる。グループの呼び出しにも使われる
- [ ] 「次のウインドウ」「前のウインドウ」は、いまのデスクトップのウインドウの中で切り替わる

## 複数のディスプレイ

- [ ] ディスプレイを 2 つつなぐと、それぞれの左端にストリップが出る
- [ ] それぞれのストリップに、そのディスプレイにあるウインドウだけが並ぶ（2 つにまたがるウインドウは、多く重なっているほう）
- [ ] ウインドウを手でほかのディスプレイへ動かすと、数秒でそちらのストリップへ移る。行をほかのディスプレイのステージへドラッグしたときも、そちらへ移る
- [ ] グループは、保存したディスプレイ（編集画面の「ディスプレイ」）のストリップにだけ並ぶ。右のディスプレイのストリップで保存したグループは、右のストリップに並ぶ
- [ ] 編集画面でディスプレイを「ポインタのあるディスプレイ」にしたグループは、どのストリップにも並ぶ
- [ ] グループを保存したディスプレイを外すと、そのグループはメインのディスプレイのストリップに並ぶ（「つながっていないディスプレイ」と出る）
- [ ] 片方のストリップでグループを並べ替えても（ドラッグ・上へ・下へ）、もう片方のグループの並びが崩れない。ショートカットの番号は全体の並び順のまま（飛び飛びになることがある）
- [ ] ほかのディスプレイのグループがあるとき、グループのないストリップには「このディスプレイのグループはありません」と出る
- [ ] 設定の「ほかのディスプレイのウインドウ・グループも出す」をオンにすると、どのストリップにもすべて並ぶ。「メインのディスプレイだけ」のときは、この設定は選べず、すべて並ぶ
- [ ] 片方のストリップで並べ替えても、もう片方の並びが崩れない
- [ ] 「次のウインドウ」「前のウインドウ」は、ポインタのあるディスプレイのウインドウの中で切り替わる
- [ ] 2 つ目のディスプレイのストリップで選ぶと、2 つ目のディスプレイに並ぶ（1 つ目のステージはそのまま）
- [ ] 1 つ目のステージに出しているウインドウを 2 つ目で選ぶと、2 つ目へ移り、1 つ目の行の枠が消える
- [ ] 並べ方・余白は、ディスプレイごとに別々に選べる
- [ ] 設定で「メインのディスプレイだけ」にすると、ストリップが 1 つになる
- [ ] ディスプレイを外す・つなぐと、ストリップが作り直される

## 型の編集画面

- [ ] 並べ方のメニュー →「新しい型…」で編集画面が開き、Dock にアイコンが出る（閉じると消える）
- [ ] 枠をドラッグで動かすとき・角で大きさを変えるとき、ポインタにぴったり付いてくる（震えない）
- [ ] 枠をドラッグで動かせる。選んだ枠の 4 つの角で大きさを変えられる。重ねても、間を空けてもよい
- [ ] 「目盛りに合わせる」をオフにすると、細かく動かせる
- [ ] 「最前面へ」「最背面へ」で番号（前後の順番）が変わる
- [ ] 「ひな形から始める」で枠が置き換わる
- [ ] 保存すると、並べ方のメニューと設定の「型」のタブに出る。その型で並べているステージは並び直す
- [ ] 「いまの並びから型を作る…」で、ステージのウインドウの並びから編集を始められる
- [ ] 設定の「型」のタブで、編集・名前の変更・複製・削除ができる

## 検索

- [ ] ⌃⌥Space で、ポインタのあるディスプレイの真ん中より少し上に検索の欄が出て、すぐ文字を打てる。前面のアプリのフォーカスは外れない
- [ ] ストリップの「ウインドウ」の見出しの🔍・メニューバーの「検索…」でも出る
- [ ] 何も打たないと、グループとウインドウがすべて並ぶ。打つと、ウインドウ名・アプリ名・グループ名で絞り込まれる（空白で区切ると、すべてを含むものだけ）
- [ ] 「ＳＡＦＡＲＩ」「さふぁり」のように、全角・ひらがなで打っても見つかる（カタカナ・半角の名前のもの）
- [ ] ↑↓ で選び、↩ でウインドウだけが出る（グループなら呼び出す）。⌘↩ でステージに足す
- [ ] 検索の欄を開いたまま数秒待っても、選んでいる行がずれない
- [ ] 日本語入力で変換している途中の ↩・↑↓ は、変換の確定・候補選びに使われる（結果を出してしまわない）
- [ ] esc・ほかをクリック・もう一度 ⌃⌥Space で閉じる
- [ ] 出す先は、検索の欄を開いたときにポインタがあったディスプレイ

## 自動化

- [ ] 「ショートカット」アプリで「Pinstage」を探すと、「グループを呼び出す」「ストリップを出す・隠す」「ステージをグループとして保存」「ウインドウ・グループを検索」が出る
- [ ] 「グループを呼び出す」でグループを一覧から選べ、動かすとそのグループが並ぶ。グループを足す・名前を変えると、一覧も変わる
- [ ] 「ストリップを出す・隠す」で、出す・隠す・切り替えるが選べて、そのとおりに動く
- [ ] 「ステージをグループとして保存」で、名前を付けて保存できる（空なら仮の名前）。ステージが空なら、理由が出る
- [ ] Pinstage を終了しているときに「ショートカット」から動かすと、Pinstage が起動して動く
- [ ] Pinstage を終了しているときに `open "pinstage://group/グループ 1"` を流すと、起動してそのグループが並ぶ
- [ ] オートメーション（例: 特定のアプリを開いたとき）で「グループを呼び出す」が動く
- [ ] ターミナルで `open "pinstage://group/グループ 1"` を流すと、そのグループが並ぶ。`open pinstage://strip/hide`・`open pinstage://search`・`open "pinstage://save?name=テスト"` も動く
- [ ] 設定の「自動化」に、グループごとの URL と、そのほかの操作の URL が並び、コピーのボタンでコピーできる

## ショートカットの変更

- [ ] 設定 →「ショートカット」で、ボタンを押してからキーを押すと割り当てられ、すぐに効く
- [ ] ほかの操作と同じキーを割り当てると、前の操作から外れたことが出る
- [ ] ⌘・⌥・⌃ のどれもないキーは割り当てられない。esc でやめられる
- [ ] 記録している途中で設定のウインドウを閉じても、ほかのショートカット（⌃⌥S など）が効く
- [ ] × で外すと効かなくなる。「初期設定に戻す」で ⌃⌥1〜9・⌃⌥S に戻る
- [ ] 変えたキーが、ストリップのグループの行とメニューバーのメニューに出る
- [ ] 終了して起動し直しても、割り当てが残る
- [ ] ⌃⌥] / ⌃⌥[ で、最後に呼び出したグループの次・前のグループが出る（端まで行ったら反対の端へ）
- [ ] 「次のウインドウを出す」「前のウインドウを出す」にキーを割り当てると、ポインタのあるディスプレイで、ストリップの並びの次・前のウインドウだけが出る
