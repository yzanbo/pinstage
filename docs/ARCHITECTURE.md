## 決まりごと

- **決められることは PinstageCore で決める**：AppKit を使わずに決められること（並べ方から枠を出す・グループと型の書き換え・デスクトップの判定）は PinstageCore に置いて、テストを付ける。アプリ側は、読んだ値を渡して、決まったことを行うだけにする
- **グループと型の書き換えは 1 つの入口から**：書き換えは StageLibrary の関数で行い、StageController の `editLibrary` で包む（変わったときだけ保存して、「ショートカット」アプリに知らせる）。
  グループの中身は、ステージから作っても、見えている画面を記録して作っても、同じ形（StageGroup.Content）にしてから入れる

- **ストリップの高さ**：ふつうのウインドウより上、「最前面に出す」ウインドウ（.floating）より 1 つ下（floating − 1）。pinshot のピンなど、利用者が最前面に置いたものをストリップより上に出すため（同じ高さだと、出した順で上下が入れ替わる）
- **ストリップはデスクトップごと**：すべてのデスクトップに付いて回ると、切り替えの途中に前のデスクトップの一覧が見えるので、デスクトップごとに置く（isOnActiveSpace で、いまのデスクトップのものを見分ける）。ウインドウは .stationary にしない（付けると切り替えのスライドの間も画面に留まり、行き先のデスクトップの上に前の一覧が残る）。ふつうのウインドウ（managed）にして、置いたデスクトップと一緒にスライドさせる。隠すときは画面から外さず（外すと置いたデスクトップを忘れるため）、透明にして画面の外へ置き、クリックを素通りさせる
- **デスクトップは非公開の API で直接見分ける**：デスクトップを扱う公開の API はないので、非公開の関数（SkyLight）を使う。
  起動したとき、すべてのディスプレイのすべてのデスクトップ（フルスクリーンのものは除く）に、前もってストリップを置く（自分のウインドウを、見ていないデスクトップへ移せる）。
  デスクトップを足した・消したら、読み直しのたび（1.5 秒ごと）と切り替えたときに合わせる。各ストリップは、自分のデスクトップにあるウインドウだけを並べる。
  ウインドウは macOS のウインドウの番号で見分ける（画面に出ているか・重なりの順番・サムネイルの照合）。
  ほかのデスクトップのウインドウは、アクセシビリティの API の一覧に出てこないアプリが多いので、RemoteWindows で見つけて一覧に足す（起動直後から、すべてのデスクトップのウインドウが分かる）。
  見つからなかったものは 30 秒たつまで探し直さない。ほかのデスクトップのウインドウを押したら、そのデスクトップへ移って前に出す（SkyLight.focus）。
  関数が見つからないとき（macOS が変わったときなど）は、下の推測の仕組みに自動で戻る
- **一覧はストリップが持つ**（非公開の API が使えないときの推測の仕組み）：ストリップは、自分のデスクトップのウインドウの一覧を持ったままにする（ほかのデスクトップを見ている間も変えない）。切り替えの動きの途中から、行き先の一覧が出ているようにするため。
  「画面に出ているウインドウの一覧」（CGWindowList）を読んだとき、同じ一覧に出ているストリップが、そのデスクトップのストリップ（操作スペースの公開の API がないので、ストリップのウインドウを目印にする）。
  切り替えの途中は両方のデスクトップのウインドウとストリップが画面に出ているので、そのときの一覧は覚えさせない（覚えさせると、行き先のストリップに前のデスクトップのウインドウが混ざる）。
  切り替えの知らせ（activeSpaceDidChange）は動きが終わる前に来ることがあるので、知らせのあと、落ち着くまで少しずつ読み直す。
  最小化したウインドウ・隠したアプリのウインドウは、覚えた一覧とは別に、どのストリップにも並べる。フルスクリーンのウインドウは、デスクトップの一覧に入れない

- **ステージはウインドウを抱え込まない**：ステージは「最前面に出すウインドウの組み合わせ」。出したり外したりしても、保存したグループは変わらない
- **ディスプレイごとのステージ**：ストリップを押したディスプレイのステージを変える。1 つのウインドウは 1 つのステージにだけ入る（別のディスプレイのステージに入れたら、前のステージから外れる）
- **型とグループを分ける**：型は並べ方の形だけ（どのアプリかは覚えない）。グループは「どのウインドウを、どの型で、どのディスプレイに」並べるか
- **座標**：ウインドウを動かす計算は、アクセシビリティの API と同じ「左上が原点」でする。ストリップの位置は AppKit の「左下が原点」でする。変換は `ScreenCoordinates` だけで行う
- **1 枚だけ出すとき**：用意した型（重ねる以外）では、設定の大きさ（そのまま・縦いっぱい・ステージいっぱい）で前に出す
- **サムネイル**：ストリップに並べているウインドウだけを、3 秒ごとに撮り直す（ストリップを隠している間・大きさが「小」のときは撮らない）。撮った画像は保存も送信もしない
- **App Sandbox は使わない**：ほかのアプリのウインドウを動かすため（アクセシビリティの API はサンドボックスの中では使えない）

## 割り切っていること

- 別の操作スペースのウインドウは、多くのアプリでウインドウの一覧に出てこない。前に見えていたウインドウは、閉じるまで一覧とステージに残す（まだ見ていないスペースのウインドウは出ない）。ストリップには、いまのスペースのウインドウだけを並べる（CurrentSpace。公開の API だけで、アプリ・位置・名前で見分ける。画面収録の許可がないと名前が分からず、同じ位置・大きさのウインドウを取り違えることがある）
- ウインドウの読み直しは、画面の処理と同じ流れで行う（変わったときだけ描き直す）。応答しないアプリがあると、一瞬止まることがある

- 登録した型の前後の順番は、ステージに出した順番で覚える（いまの並びから型を作るとき、実際の重なりの順番は読まない）
- 見えている画面の記録では、重なりの順番を画面に出ているウインドウの一覧（CGWindowList。前から後ろの順）から読む。ウインドウとは、アプリ・名前・枠で照らし合わせる（CurrentSpace.frontToBack）。照らし合わせられなかったウインドウは記録に入らない。記録した枠はステージに対する割合で覚えるので、ステージの外（ストリップの後ろなど）にはみ出したところは切れる
- 記録したグループを呼び出したとき、見つからなかったメンバーの枠は抜いて当てはめる（ほかのウインドウの枠がずれないように）
- （非公開の API が使えないときだけ）初めて訪れたデスクトップには、着いてからストリップを作る（まだ見ていないデスクトップにウインドウを置く公開の API がない）。そこへの切り替えの途中に、前のデスクトップのストリップへ紛れ込んだウインドウは、着いたあとで外す（入ってから 5 秒までのもの）
- ほかのデスクトップのストリップの一覧は、最後にそのデスクトップを見たときのもの。見ていない間にそのデスクトップで開いた・移したウインドウは、着いてから一覧に入る
- 自分のウインドウを出した・動かした結果は、次の描画まで「画面に出ているウインドウの一覧」に出てこない。作ったばかりのストリップは、1 秒までは一覧になくても、いまのデスクトップにあるものとして扱う
- サムネイルのウインドウは、アプリ・名前・枠で照らし合わせる（非公開の API でウインドウの番号を読むことはしない）
